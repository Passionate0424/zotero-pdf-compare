# Zotero PDF Compare · PDF 译文对照阅读

在 Zotero 中导入已有译文 PDF，使用原文、译文和左右对照三种模式阅读，保留原文的原生批注功能。

## 安装

从 [Releases](https://github.com/Passionate0424/zotero-pdf-compare/releases/latest) 下载 `.xpi` 文件，在 Zotero 的“工具 → 插件 → 齿轮 → 从文件安装插件”中选择它。

支持 Zotero 10.0，实际验证环境为 Windows / Zotero 10.0.7。兼容范围由安装包清单限定。

## 使用

打开原文 PDF，点击“导入译文”选择已翻译的 PDF。译文会复制为附件并与原文配对，之后可以切换“原文”“译文”“对照”。支持更换译文及重复文件复用。

- “联动”：开启或关闭两侧滚动同步。
- “互换”：交换原文和译文的左右位置。
- “同步缩放”：同步倍率和当前查看区域，与滚动开关独立。
- 拖动中间分隔条调整宽度，双击恢复均分。

原文保留 Zotero 原生批注；插件内译文窗格只读。配对和阅读设置保存在本机配置中。卸载插件后，已导入的译文附件继续保留。

## 功能边界

本版本需要用户提供已翻译的 PDF，没有自动翻译后端。无需安装 Python、Java 或本地翻译引擎即可使用插件。同步支持单页纵向连续布局；页数不一致、横向或双页布局会暂停联动。扫描或图片型译文的文字选择能力取决于其文字层。

隔离测试中已验证导入、批注、模式切换、滚动缩放、禁用卸载和备份恢复。少量导航和冷启动测试出现过偶发失败，后续重测通过，稳定性仍需持续观察；与其他插件共存尚未全面验证。

## 开发与 CI

开发和构建需要 Node.js 24、Python 3.11+。单元测试使用 Node 内置模块，不需要先安装浏览器依赖。

```sh
npm test
python tools/build-dev-xpi.py --release
```

GitHub Actions 在 Windows 和 Linux 上运行单元测试、语法和发布包检查；推送 `v版本号` 标签后自动发布 XPI、SHA-256 与更新清单。真实 Zotero 测试需要项目独立实例，见 [回归说明](docs/REGRESSION.md)，云端 CI 不代表真实窗口交互验收。

历史工程资料和实验性浏览器后端保留在仓库中，发布包使用明确的文件白名单，不包含运行数据、浏览器状态或实验后端。
