# 手动导入译文

当前仅安装在本项目的独立测试 Zotero，版本 0.3.1。无需启动辅助程序或豆包浏览器。

1. 在豆包或其他工具中翻译，并手动下载 PDF。
2. 在测试 Zotero 打开对应原文，点击工具栏“导入译文”。也可在文献列表右键具体原文 PDF，选择“导入已有译文 PDF…”。文献有多份原文 PDF 时必须选具体附件。
3. 在文件选择框选择下载好的译文。插件复制文件到 Zotero 附件存储，保留下载文件和原文，然后打开对照。
4. 用“原文 / 译文 / 对照”切换。“联动”可关闭。每次进入对照默认左右均分，拖动中间分隔条调整，双击恢复均分。

已配对时入口显示“更换译文”。相同文件会复用已有附件；更换后旧译文仍保留，不自动删除。独立 PDF 可以配对为同库的两个独立附件，不会被强制移到新条目下。

对照模式新增两个按钮，两侧都可操作：

- **互换**：交换原文和译文的左右位置，原文仍使用同一个原生阅读器，批注功能随原文移到另一侧。
- **同步缩放**：默认开启。任一侧百分比缩放时，另一侧跟随相同倍率；使用“适应宽度/页面”等预设时，两侧采用相同适应模式。缩放同步还会同步当前页内的视口中心位置，包括横向、纵向，方便放大查看同一局部区域。

“联动”与“同步缩放”独立：同时开启时，后续上下或横向移动也持续跟随；关闭“联动”后，缩放操作仍同步当时的查看区域，随后可以各自移动。关闭“同步缩放”后可以各自缩放。蓝色表示开启。左右顺序与缩放开关会保存为下次打开对照的默认选择。

区域对应按同页的相对坐标计算，不是段落语义匹配。页边缘受可滚动范围限制时会尽量对齐；两侧可视尺寸不同，不能保证显示范围完全相同。翻译重排、缺失或裁切的内容不会由此恢复。

原文继续使用 Zotero 原生阅读器和批注，批注归属原附件。原文的批注侧栏会占用原文栏内部空间，侧栏展开时，两张 PDF 的可见正文宽度可能不同；左右阅读器外框仍默认均分。译文窗格只读。

文件需为可完整读取、无需密码、256 MB 以内的 PDF。原译文页数不同时仍可阅读，但暂停联动并说明原因。相同页码、页内比例的联动不等同于语义段落对齐；译文重排或缺页会影响对应关系。

取消选择不会导入。导入失败时撤销本次新建附件与配对更改；不会删除原文或此前已有译文。校验包括 PDF 文件头、逐页文本提取完成、复制前后 SHA-256；不是所有页面的视觉保真保证。

测试库禁止同步。此版配对记录存于本机配置，尚未实现跨设备配对同步；不能因附件可由 Zotero 同步而认为另一设备也能自动恢复插件配对。文件选择框使用 Zotero 原生接口，脚本测试替代了选择结果，尚未单独人工验收系统选择框操作。
