# 首版验收清单

条目状态以实际验收为准。日志必须记录环境、样本、步骤、观察值与结果。模拟测试通过不自动勾选真实集成条目。P0 结果见 reports/P0.md；产品功能和 UI-01–08 仍待后续阶段验证。

## A：隔离（P0）

- [x] 测试 profile、数据与 storage 为独立路径；复用现有程序，受监测的共享安装文件保持原样。
- [x] 路径/配置失败先停止，端口启动前预检、连接前核实回环地址与进程归属；不回退默认 profile。
- [x] 无正式同步账号，自动同步、个人/群组文件同步关闭。
- [x] 测试 Connector 服务关闭；启动日志与探针确认跳过 Word/LibreOffice 自动安装；未执行默认关联操作，程序自动升级关闭。
- [x] 仅备妥公开副本，空库无正式文献；6 个已登记保护文件与首次基线一致。不是对活跃正式库做全量备份或全盘写入审计。
- [x] 正常关闭仅测试实例，开发调试端口关闭，日常父进程仍在运行。

## B：原文原生批注（P1，必需）

- [ ] 已有高亮、评论等批注正确显示，身份、归属与位置不变。
- [ ] 当前目标 Zotero 支持的原生批注工具逐项测试：创建、编辑、改色、评论、标签与删除。
- [ ] 添加到笔记、复制及拖拽批注按原生行为工作；引用可以定位回原文。
- [ ] 原文单栏和对照模式均通过；切换、关闭重开和重启后记录保留。
- [ ] 禁用/卸载测试插件后，原文及批注仍可原生使用。
- [ ] 关闭时未保存操作有明确处理；保存失败不被吞掉并误报成功。
- [ ] 只读库和只读批注仍遵守 Zotero 权限。

## C：三模式与滚动（P2）

- [ ] 原文/译文/对照模式切换，位置恢复合理，连续 20 次切换无重复标签或残留 pane。
- [ ] 左侧及右侧各完成滚轮、拖动滚动条、键盘、跳页、首页与末页测试。
- [ ] 样本所有 19 页均检查对应页；同一视口锚点的页内比例误差目标不超过 0.02，页面边缘/夹取例外单独记录。
- [ ] 在登记的测试硬件下，同步响应延迟目标 P95 ≤ 100ms；至少采样 100 次，异常值与测量方式另记。未达标不隐瞒为已满足。
- [ ] 不同缩放、适应宽度、调整窗格比例与窗口大小后无持续漂移或反复跳动。
- [ ] 原文选择文本、编辑批注及拖入笔记时，联动不反向抢位置。
- [ ] 关闭联动可独立导航，重新开启时按明确操作侧对齐。
- [ ] 页数不同不静默错配；关闭标签后同步计时器和事件被清理。

## D：豆包与下载（P3）

- [ ] 新会话上传、发送、重新定位附件、打开预览、开始翻译和译文下载真实成功。
- [ ] 等待真实下载事件并检查下载完成，逐页解析有效；不把预览出现中文当完成。
- [ ] 公开 19 页样本至少完成 3 次独立任务，逐次记录耗时、页数、结果和页面变化；已有单次成功不计作 3 次。
- [ ] 登录失效、网页控件变化、断网、超时、取消均有明确状态，不导入半成品。
- [ ] 重复提交去重；串行任务互不操作对方的会话或下载。
- [ ] 日志、错误和发布包无登录凭据。

## E：归档与回退（P4–P5）

- [ ] 译文归属正确文献；独立附件也能关联；多 PDF/补充材料条目不误配。
- [ ] 原文、已有批注未被覆盖，导入结果为独立 Zotero 存储附件。
- [ ] 重复点击、重启、下载成功未导入和导入后中断不会造成重复附件。
- [ ] 禁用/卸载后原生阅读布局恢复，无残留后台任务继续归档。
- [ ] 新增附件可通过任务清单精确定位；清理演练仅针对测试库且不误删原文。
- [ ] 在关闭的独立测试环境中，完成一次完整备份和恢复演练，并校验数据库可打开、原文可读、批注与附件数量一致。
- [ ] 已记录支持版本、已知限制、备份范围、恢复步骤和候选包指纹。

既有豆包导出为图片型 PDF，第 3 页部分公式截断；该现象应保留在已知限制中，不能因归档成功而标记为内容保真通过。

## F：视觉 UI 与真实交互（P1/P2/P5 必需）

脚本逻辑、真实阅读器交互和视觉检查分开记录。视觉证据来自实际 Zotero 测试窗口，不以网页样机、DOM 存在或按钮可点击替代。每张图记录版本、窗口尺寸、缩放/DPI、主题、样本页号与模式；截图仅保存测试窗口，避免包含用户日常窗口。

- [ ] UI-01 原文模式：原生工具栏、页面、批注侧栏完整，无遮挡、截断或插件残留空白。
- [ ] UI-02 译文模式：页面比例、清晰度与按钮状态合理；图片型译文的文字层限制不以可划词外观误导。
- [ ] UI-03 对照模式：左右各自工具栏可用，分隔条可拖，侧栏展开后仍可读；页内对齐截图与几何值对应。
- [ ] UI-04 批注交互：选词、颜色菜单、评论/标签弹窗、添加到笔记、拖拽等状态实际操作后检查；焦点、弹窗和鼠标命中区域正常。
- [ ] UI-05 窗口布局：至少 1280×800 和 1600×1000；调窄、最大化、侧栏展开、连续拖动分隔条，无覆盖或不可达按钮。
- [ ] UI-06 明暗主题及 DPI：两种主题检查可读性、选中/禁用状态和焦点；记录本机实际 DPI。额外 DPI 组合未测须明确列为未覆盖，不能宣称全覆盖。
- [ ] UI-07 任务界面：排队、等待登录、翻译、下载、完成、失败和取消均有可理解状态，不泄露 Cookie 或内部异常堆栈。
- [ ] UI-08 卸载恢复：禁用前后截图对照，原生工具栏与布局恢复，无失效按钮或空白译文窗格。
- [ ] 每项包含截图与检查结论；重叠、裁剪、焦点丢失、侧栏挤压等问题列入阻断项。未经截图检查不标记视觉通过。

P0 至少记录独立实例初始窗口，作为环境标识；P1 必须通过 UI-01/03/04，P2 通过 UI-01–06，P4 通过 UI-07，P5 通过 UI-08 并复查全部适用项。首版视觉基线建立后再评估截图差异回归，不将首次截图自动当成正确基线。
