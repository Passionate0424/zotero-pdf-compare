# 首版验收清单

全部条目初始状态为未验证。日志必须记录环境、样本、步骤、观察值与结果。模拟测试通过不自动勾选真实集成条目。

## A：隔离（P0）

- [ ] 测试 profile、数据与 storage 均为独立路径，目录最终解析后不落入正式环境；允许复用现有程序，但共享安装文件不被改写。
- [ ] 启动失败、端口占用或配置缺失时安全退出，不回退默认 profile、不连接正式实例。
- [ ] 无正式账号同步配置，测试同步关闭。
- [ ] 测试 Connector HTTP 服务关闭，不占用正式 23119；不向 Word/LibreOffice 安装测试集成或改默认应用关联。共享程序不由测试实例升级。
- [ ] 测试文件均为副本；正式程序与正式配置未因安装测试版修改。
- [ ] 关闭测试环境后，仅测试进程与登记资源被释放；日常 Zotero 不被终止。

## B：原文原生批注（P1，必需）

- [ ] 已有高亮、评论等批注正确显示，身份、归属与位置不变。
- [ ] 当前目标 Zotero 支持的原生批注工具逐项测试：创建、编辑、改色、评论、标签与删除。
- [ ] 添加到笔记、复制及拖拽批注按原生行为工作；引用可以定位回原文。
- [ ] 原文单栏和对照模式均通过；切换、关闭重开和重启后记录保留。
- [ ] 禁用/卸载测试插件后，原文及批注仍可原生使用。
- [ ] 关闭时未保存操作有明确处理；保存失败不被吞掉并误报成功。
- [ ] 只读库和只读批注仍遵守 Zotero 权限。

## C：三模式与滚动（P2）

- [ ] 原文/译文/对照模式切换，位置恢复合理，连续 20 次切换无重复标签或残留 pane。
- [ ] 左侧及右侧各完成滚轮、拖动滚动条、键盘、跳页、首页与末页测试。
- [ ] 样本所有 19 页均检查对应页；同一视口锚点的页内比例误差目标不超过 0.02，页面边缘/夹取例外单独记录。
- [ ] 在登记的测试硬件下，同步响应延迟目标 P95 ≤ 100ms；至少采样 100 次，异常值与测量方式另记。未达标不隐瞒为已满足。
- [ ] 不同缩放、适应宽度、调整窗格比例与窗口大小后无持续漂移或反复跳动。
- [ ] 原文选择文本、编辑批注及拖入笔记时，联动不反向抢位置。
- [ ] 关闭联动可独立导航，重新开启时按明确操作侧对齐。
- [ ] 页数不同不静默错配；关闭标签后同步计时器和事件被清理。

## D：豆包与下载（P3）

- [ ] 新会话上传、发送、重新定位附件、打开预览、开始翻译和译文下载真实成功。
- [ ] 等待真实下载事件并检查下载完成，逐页解析有效；不把预览出现中文当完成。
- [ ] 公开 19 页样本至少完成 3 次独立任务，逐次记录耗时、页数、结果和页面变化；已有单次成功不计作 3 次。
- [ ] 登录失效、网页控件变化、断网、超时、取消均有明确状态，不导入半成品。
- [ ] 重复提交去重；串行任务互不操作对方的会话或下载。
- [ ] 日志、错误和发布包无登录凭据。

## E：归档与回退（P4–P5）

- [ ] 译文归属正确文献；独立附件也能关联；多 PDF/补充材料条目不误配。
- [ ] 原文、已有批注未被覆盖，导入结果为独立 Zotero 存储附件。
- [ ] 重复点击、重启、下载成功未导入和导入后中断不会造成重复附件。
- [ ] 禁用/卸载后原生阅读布局恢复，无残留后台任务继续归档。
- [ ] 新增附件可通过任务清单精确定位；清理演练仅针对测试库且不误删原文。
- [ ] 在关闭的独立测试环境中，完成一次完整备份和恢复演练，并校验数据库可打开、原文可读、批注与附件数量一致。
- [ ] 已记录支持版本、已知限制、备份范围、恢复步骤和候选包指纹。

既有豆包导出为图片型 PDF，第 3 页部分公式截断；该现象应保留在已知限制中，不能因归档成功而标记为内容保真通过。
