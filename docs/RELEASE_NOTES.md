PDF 译文对照阅读支持手动导入已有译文 PDF，并提供原文、译文和左右对照模式。

- 保留原文 Zotero 原生批注，译文窗格只读。
- 双向滚动、左右互换、独立同步缩放和查看区域。
- 对照工具栏随窗口与分栏宽度自动对齐。
- 附件去重、更换译文和本机配对记录。

适用于 Zotero 10.0，实际验证为 Windows / Zotero 10.0.7。下载 `.xpi` 后通过 Zotero 插件菜单安装；无需本地翻译引擎。自动翻译尚未接入，原文和译文页数需一致才能联动。内部标识保留以兼容旧安装。

发布附带 SHA-256 和自动更新清单。真实 Zotero 阅读与恢复演练已完成，云端 CI 覆盖单元测试、构建及包结构；其他插件共存与低频导航、冷启动问题仍需持续验证。
