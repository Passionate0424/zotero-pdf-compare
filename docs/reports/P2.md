测量方法：在测试 PDF 文档中发出操作侧意图，再改变原生滚动容器位置，计时到另一侧实际 scrollTop 对齐。开始前仅将后台窗口布局准备好；120 个计时区间使用正常计时器，没有强制推进绘制。它不是系统输入到屏幕呈现的延迟测量。页尾受视口高度限制时无法将最后一页顶部置于屏幕顶部，末页导航按实际滚动边界判定，不放宽非边界精度。

## 尚未通过的验收

`bidirectionalNavigation` 保留 false。可信 Gecko 滚轮事件已在左右实际产生滚动并保持对齐；PageDown 和滚动条探查没有可靠产生滚动。事件到达不等于真实输入已通过，不能用直接改 scrollTop 代替这两项。用户 P1 手测仍有效，但没有将其延伸为 P2 新增输入全部通过。

清醒后仅需补验：在对照模式左右各用键盘和实际滚动条拖动，确认另一侧跟随、松手后可换侧操作。未通过前不生成 milestone/p2。P3 独立模块可继续开发，不能据此把 P2 改成完成。

## 视觉检查

已逐张检查 [P2.json](P2.json) 登记的 7 张真实测试窗口截图，涵盖阅读器明/暗主题、1280×800、1600×1000、原文、译文、对照、最大化和侧栏展开。应用外框保持原来的深色；没有声称覆盖应用全局浅色外框或其他 DPI。

原文工具栏、批注侧栏与已有高亮保留；译文没有可写批注工具；按钮选中/禁用状态清楚。视觉复核发现译文单栏误显示“布局不支持”，已修正为只在对照模式提示布局限制并复拍。窄栏侧栏展开时正文较小，可以关闭原生侧栏或拖动分隔条。图片型译文在暗色阅读器中对比度偏低，沿用原生颜色方案，可单独切回浅色；既有豆包公式截断与无文字层仍属于内容限制。

## 调试记录与边界

- 跨文档 scrollTo 参数未生效，改用原生 scrollTop；几何改用稳定的 offsetTop/offsetHeight，避免异步滚动与 getBoundingClientRect 混用造成整页误差。
- 后台窗口可能延迟滚动事件，增加 24ms 两个数值偏移探查；只在变化时读取页几何。销毁时清除轮询、合并定时器、观察器和监听器。
- 快速换侧与页尾夹取复测暴露旧待处理动作拉回新位置，加入输入侧优先及清除相反侧待处理任务；夹取样本留出事件收尾，不计入 120 次非边界延迟样本。
- 适应宽度会在容器调整后改变页尺寸，观察页容器和首页尺寸；后台准备绘制与性能计时明确分开。固定等 250ms 的早期缩放测试出现 0.545 临时误差，最终等待自动布局稳定后通过，无测试代码手动调用 alignFrom 修正窗口调整结果。
- 一次定位不准确的文本替换引入非 async 函数中的 await，已修正；构建先对所有 JS 解析检查，安装报告同时要求实际控制器加载，不能仅凭 isActive 宣称成功。
- 当前自动联动支持单页纵向连续布局；双页、横向或页数不同会暂停，不做语义段落匹配。
