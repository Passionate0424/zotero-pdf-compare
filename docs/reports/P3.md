## 实现与限制

每任务独立浏览器上下文，按顺序操作新会话；发送后重新解析服务器会话与附件卡片，拒绝把 local_ URL 当服务器成功。等待真实下载完成，经过 PDF 头、大小、每页解析与渲染、页数、指纹检查后才提供结果。失败/取消没有可归档成功结果。

任务状态保存采用排他锁、写盘和原子替换。中断不静默重传；重试为显式操作。取消和超时先关闭自己的上下文并等待清理，再允许下一任务；完成文件被删除或更改会撤销成功。错误只有固定代码/中文说明，不保存原始浏览器异常或登录凭据。

首次受限运行下，临时目录重命名/链接操作和 Chrome 下载遭到环境限制；获得自动许可后测试通过，没有降低生产文件原子保存要求。一次取消后的 Windows 临时目录清理出现 ENOTEMPTY，已复用同一浏览器关闭 promise 并为专属目录清理加入有限重试，最终完整集成进程正常退出。

本轮没有 Computer Use、日常浏览器接管、正式 Zotero 安装或附件导入。无完整平台/浏览器兼容保证；仅单页纵向阅读布局在 P2 被支持。已有译文的公式截断、图片型 PDF 限制继续保留。

使用与任务协议见 [WORKER.md](../WORKER.md)。验收摘要为 [P3.json](P3.json)，原始不含凭据的本机/线上结果汇总为 [P3-evidence.json](P3-evidence.json)。真实重新登录与 3 次线上下载通过前，不生成 milestone/p3。
