# 回归检查

`npm run hooks:install` 在当前仓库配置版本化的 `.githooks`；若已有其他 hook 路径则拒绝覆盖。`git commit` 自动执行 `npm run check`：检查暂存内容空白错误、代码变更是否同时暂存工程日志、代码语法和完整单元测试。检查执行工作区代码，因此拒绝代码和测试文件部分暂存。检查不启动 Zotero，也不操作浏览器。Git 配置为本地配置，克隆仓库后需要重新安装。

`npm run test:native` 是真实 Zotero 回归：先验证项目隔离实例，再顺序执行原生批注、模式切换、分隔条拖动、工具栏布局、缓存、互换和同步缩放、导航清理。任一失败即返回非零；结果与截图归档在 `artifacts/`。它要求独立测试实例已启动，使用现有开发测试文献，会改变该测试窗口的尺寸、标签和阅读位置，因此不在每次提交时自动执行。测试完成后应再次运行 `npm run dev:verify`。

截图不是自动的审美判断：界面改动需人工查看相关截图，检查深浅主题和窗口尺寸；坐标、尺寸与状态断言是自动判断。真实鼠标滚轮、拖动和键盘体验，以及豆包在线翻译不在此快速门禁覆盖范围；现有未完成的 P2/P3/P5 门槛不因这些测试通过而完成。自动化结果可能受机器负载影响，失败需保留报告并排查，不能直接忽略。
